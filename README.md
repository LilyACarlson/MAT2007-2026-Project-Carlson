# Beatles Love Lyrics Percentage Script
# Script Functions

The purpose of this script is to help the user determine the total number and percentage of words belonging to a set of target words out of a collection of total words. The demonstration script uses Beatles lyrics. To run the demonstration script, you will need to have The Beatles Discography & Lyrics Dataset downloaded. This can be found at https://www.kaggle.com/datasets/larissapavan/the-beatles-discography-and-lyrics-dataset. 

# Script Outputs

The script calculates the total occurences of the target words per album, and plots them. It also calculates the percentage that the target words make up of the total words and plots this along with the standard deviation per album. It generates these plots as 'Beatles bar chart.png' and 'Beatles Graph.png'. 

# How to run
In order to run and use this program, you will need to have numpy, pandas, matplotlib, and scipy installed. You can install any of these using the "pip install [package]" command. If this does not work, you may need to seek out advice for your specific circumstance.
