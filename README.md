# Determine and Plot the Percent of Words Which Belong to A Given Set
For course MAT2007 2026

The purpose of this script is to help the user determine the total number and percentage of words belonging to a set of target words given by the user. The demonstration script uses Beatles lyrics, but with small tweaks, could be used for any dataset. The script calculates the total occurences of the target words per album, and plots them. It also calculates the percentage that the target words make up of the total words and plots this along with the standard deviation per album. 

In order to run and use this program, you will need to have numpy, pandas, matplotlib, and scipy installed. You can install any of these using the "pip install [package]" command. If this does not work, you may need to seek out advice for your specific circumstance. To run the demonstration script, you will need to have The Beatles Discography & Lyrics Dataset downloaded. This can be found at https://www.kaggle.com/datasets/larissapavan/the-beatles-discography-and-lyrics-dataset.
